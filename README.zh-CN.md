# AI 虚拟陪伴数字纪念网站

[English README](README.md)

这是一个交互设计与前端原型：用户可以根据人物或宠物的照片、性格、表达方式和真实回忆，创建一份有边界的虚拟陪伴档案。

> **项目状态：** 当前对话采用透明的本地规则逻辑，尚未连接生成式 AI 模型，也不声称能够复刻真实人格、意识或生命。

## 项目目标

数字纪念产品能够帮助人们保存珍贵细节，但也可能带来隐私、授权、身份冒充和情感依赖风险。本项目探索一种更克制的产品方向：以真实资料支持陪伴体验，但不让 AI 假装成真实的人或动物。

## 已实现功能

- 创建人物或陪伴动物档案
- 上传 JPG、PNG 或 WebP 图片，并进行格式和大小验证
- 记录关系、性格、表达方式和一段真实回忆
- 编辑过程中实时预览档案
- 创建前确认资料使用权与 AI 身份说明
- 使用 IndexedDB 将档案保存在当前设备
- 进入带有明确 AI 标识的本地陪伴聊天体验
- 支持电脑和手机响应式布局
- 支持完整中英文切换、浏览器语言识别与语言偏好记忆
- 在支持的浏览器中通过 WebMCP 填写档案草稿

## 隐私与安全设计

- **本地优先：** 原型中的照片和回忆仅保存在当前浏览器。
- **授权确认：** 用户需要确认自己有权使用所提供的资料。
- **AI 身份披露：** 界面不会把陪伴角色描述成真实对象本人。
- **回忆边界：** 回应不主动编造用户没有提供的共同经历。
- **避免依赖设计：** 不使用连续签到、内疚提示或情感绑架促进留存。

## 本地运行

项目无需安装依赖或执行构建：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 技术实现

- 语义化 HTML
- 响应式 CSS
- 原生 JavaScript
- FileReader API 与 IndexedDB
- WebMCP 渐进增强

## 当前限制

- 对话是规则驱动的产品原型，并非生产级 AI 服务。
- 档案只保存在一个浏览器中，无法跨设备同步。
- 尚未实现账户、加密云存储、声音克隆或实时数字人。
- 清除浏览器网站数据会删除已保存档案。
- 本项目不是心理健康服务或哀伤辅导工具。

## 后续路线

- 接入只依据用户资料回答的可选 AI 对话后端
- 在界面中明确区分原始回忆与模型生成语言
- 加入账户、加密存储和彻底删除数据能力
- 建立对象授权记录、争议处理与下架机制
- 在生产化之前进行哀伤安全审查和用户研究

## 负责任使用

请勿将本项目用于冒充真实人物、绕过身份验证、误导第三方，或在未获授权时克隆他人的肖像与声音。任何正式上线的产品都应根据运营地区接受专门的隐私和法律审查。
